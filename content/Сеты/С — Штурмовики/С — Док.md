# Модификации:
## 1. База новичка

![[doc_m1.jpg]]

Итог статы при прокачке 2 слота до миф: урон по хп +11%, бб +14, пробивная +5, перезарядка +10%, дальность прицел -27, урон по броне -7%
Итог статы с лег. 2 слотом(то, что на картинке): урон по хп +11%, бб +12, дальность прицел -24, урон по броне -7%

Почему в 1 слоте прокачка только до серого мода: большие траты, малое повышение дпс (+1.2-1.4%)

Почему левые ветви модов: + к нужным статам (урон по здоровью, бб) и - к ненужным (приц. дальность и урон по броне, при 2 миф моде перезарядка). В остальных ветках наоборот. Что делают хар-ки написано в гайдах Дето

Можно уменьшить штрафы: перс перчатка для + к прицельной и урону по броне, улучшалки на карте
2 слот можно качнуть до миф для бб

ОБЩИЙ ИТОГ: + к урону (модиф + бб), меньше прицел дальность (при ходьбе норм) и медленнее снос брони. Для новичка урон на доке хорошо зайдёт из-за невостребованности пробития до глобала(10к)
